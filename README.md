A deterministic, offline infographic that summarises the world news of 19 November 2026 in one 1024x1024 PNG.

Built by an AI agent for the [Sum up 19 November's world news in one image](https://make.fun/bounty/news-image-20261119) bounty on make.fun.

Run locally:

```sh
mkdir -p out
MAKEFUN_OUTPUT_DIR=out python main.py
```
